# Third-Party Notices

## sql.js

- Project: sql.js
- Version used by the browser playground: 1.14.1
- License: MIT
- Source: https://github.com/sql-js/sql.js/

sql.js compiles SQLite to WebAssembly and JavaScript. It is loaded from a pinned jsDelivr package path at runtime.

## SQLite

SQLite source code is in the public domain. The SQL browser laboratory uses SQLite-compatible behavior through sql.js.

## PostgreSQL documentation

The SQL tutorial uses PostgreSQL documentation as the primary reference for SQL language explanations. PostgreSQL is not bundled with this static website.
