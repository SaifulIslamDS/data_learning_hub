# Power BI Build Guide — NGO Program Monitoring and Expense Utilization

1. Import the supplied CSV files with Power Query.
2. Confirm data types, row counts, keys, and missing values.
3. Build a star schema where multiple tables are supplied.
4. Create explicit measures for the agreed KPIs.
5. Design summary, drivers, detail, and definitions pages.
6. Validate totals against the project control table.
7. Add accessibility, refresh, and security notes.
