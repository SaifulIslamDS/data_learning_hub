NULL and Three-Valued Logic

01

What NULL and Three-Valued Logic means

NULL represents a missing or unknown value, not zero or an empty string. Comparisons with NULL do not return true or false; they return unknown, so IS NULL and IS NOT NULL are required. The important first step is to define the row population and result grain before interpreting any returned value. SQL syntax is only useful when it represents the intended business question.

SQLSELECT customer_id, customer_name, city FROM customers WHERE city IS NULL;
02

How a data analyst uses it

Missing values affect counts, averages, joins, and classifications. Analysts must distinguish genuinely unknown values from not-applicable values and decide how each metric handles them. A responsible workflow records the filter rules, validates row counts, checks NULL behavior, and reconciles important totals before publishing the result.

03

Rules, dialect notes, and common mistakes

The browser practice uses SQLite through sql.js. The course explanation emphasizes portable SQL and identifies PostgreSQL syntax where it differs. Query results are temporary and remain in the current browser page. Common mistakes include using the wrong grain, relying on implicit conversion, omitting deterministic ordering, or treating missing values as ordinary zeroes. Test the smallest useful result before extending the query.

Vocabulary

Key terms

NULL

A marker for missing or unknown data.

Unknown

The third logical state produced by some NULL comparisons.

IS NULL

Predicate used to identify NULL values.

Not applicable

A business reason a value may intentionally be absent.
