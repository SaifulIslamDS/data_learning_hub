Excel Errors and IFERROR

Diagnose error values instead of hiding them, and use IFERROR only when an expected fallback is legitimate.

01

What is Excel Errors and IFERROR?

Common errors include #DIV/0!, #N/A, #VALUE!, #REF!, #NAME?, #NUM!, #NULL!, and #SPILL!. IFERROR returns a fallback for any error; IFNA handles only #N/A.

Excel=IFERROR(A2/B2,0)
Example

=IFERROR(A2/B2,0)

02

How data analysts use it

Errors reveal broken references, missing lookups, wrong data types, invalid calculations, unsupported names, or blocked dynamic arrays. They are diagnostic signals.

Example

XLOOKUP may not find an unknown product code.

03

Rules, checks, and good practice

Fix the cause first. Use IFERROR for a defined business outcome such as “Not found,” not to replace every defect with zero. Keep an error-check sheet for critical models.

Example

Before sharing the workbook, confirm the result against an independent check and document any assumption.

Vocabulary

Key terms

Error value

A special result indicating a formula problem.

#N/A

The requested value is not available or not found.

#REF!

A reference is invalid, often after deletion.

IFERROR

Returns an alternative result when an expression errors.

Example

Handle missing product lookups

XLOOKUP may not find an unknown product code.

  1. 1

    Confirm whether the code is genuinely absent or mistyped.

  2. 2

    Use XLOOKUP’s if_not_found argument or IFNA.

  3. 3

    Return “Unknown product” rather than zero price.

  4. 4

    Report unmatched codes for correction.

Conclusion

A controlled fallback should preserve the meaning of missing or invalid data.
