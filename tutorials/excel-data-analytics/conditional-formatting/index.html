01

What is Conditional Formatting?

Conditional formatting changes cell appearance based on values or formulas. Rules include highlights, top or bottom values, data bars, color scales, icon sets, and custom formulas.

How data analysts use it

Analysts use it to flag overdue cases, budget variance, duplicates, missing fields, thresholds, and trends in compact tables.

03

Rules, checks, and good practice

Choose accessible colors, state the rule, manage rule order and Stop If True behavior, use formula anchoring correctly, and never rely on color as the only communication channel.

Example

Before sharing the workbook, confirm the result against an independent check and document any assumption.

Vocabulary

Key terms

Conditional format

A style applied when a rule is true.

Formula rule

A conditional-format rule driven by a formula.

Color scale

A gradient mapping values to colors.

Rule precedence

The order in which overlapping rules are evaluated.
