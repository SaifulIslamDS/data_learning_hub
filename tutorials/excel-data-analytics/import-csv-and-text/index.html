Import CSV and Text Files

Import delimited files without losing leading zeros, dates, encodings, or column structure.

01

What is Import CSV and Text Files?

CSV stores plain-text rows separated by delimiters and does not preserve Excel formulas, formats, multiple sheets, or data types. Opening a CSV directly may let Excel guess types; importing through Get Data provides more control.

ExcelData → Get Data → From Text/CSV
Example

Data → Get Data → From Text/CSV

02

How data analysts use it

Analysts regularly receive exports from systems. The import step should confirm encoding, delimiter, header row, decimal convention, date interpretation, and identifier columns before loading.

Example

A file contains customer_id 00125 and dates in day-month-year format.

03

Rules, checks, and good practice

Preserve the original file, record the import settings, use Power Query for recurring imports, and compare imported row counts and totals with the source.

Example

Before sharing the workbook, confirm the result against an independent check and document any assumption.

Vocabulary

Key terms

CSV

A plain-text comma-separated values file.

Delimiter

The character separating fields, such as comma or tab.

Encoding

The character representation used by a text file.

Locale

Regional settings that affect date and number interpretation.
