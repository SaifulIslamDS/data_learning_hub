Observations, Variables, and Values

Learn the basic grammar of a dataset: each observation represents an entity or event, each variable records a characteristic, and each cell contains a value.

◷ 35 minBeginner
ObjectivesLearnExampleTry itExercisesSummary
Start here

What you will learn

  • Identify observations in a dataset.
  • Distinguish variables from values.
  • Choose an appropriate unit of observation.
  • Recognize identifiers and measures.
01

Observation

An observation is one recorded case. It may represent a person, order, product, visit, day, transaction, or machine reading. The unit of observation must be consistent within a table. If one row is an order and another row is a customer total, the table mixes levels and becomes difficult to analyze.

02

Variable

A variable is a characteristic that can vary across observations: age, district, revenue, date, or satisfaction rating. Variables have definitions, units, allowed values, and roles. The same word can mean different things unless its operational definition is documented.

03

Value and identifier

A value is the recorded entry for one variable and observation. An identifier distinguishes observations, such as order_id. An identifier may look numerical but is usually categorical: averaging customer IDs is meaningless.

Vocabulary

Key terms

Observation

One entity or event represented by a row.

Variable

A characteristic measured or recorded for observations.

Value

The entry at the intersection of an observation and variable.

Identifier

A field used to uniquely distinguish records.

order_id = ORD-1008
Example

Customer-order table

A table contains order_id, order_date, customer_id, city, quantity, and revenue.

  1. 1

    Choose “order” as the unit of observation.

  2. 2

    Each row should represent one order.

  3. 3

    order_id is the identifier.

  4. 4

    city is a categorical variable; quantity and revenue are numerical variables.

  5. 5

    The value 3 under quantity belongs to one particular order.

Conclusion

Clear row meaning prevents accidental double counting and invalid aggregation.
