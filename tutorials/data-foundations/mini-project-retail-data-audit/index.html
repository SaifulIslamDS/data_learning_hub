Mini Project: Audit a Retail Dataset

Apply the entire Data Foundations tutorial to a documented retail-sales CSV. Define questions, inspect structure, profile quality, organize findings, and write a responsible analytical brief.

◷ 90 minBeginner
ObjectivesLearnExampleTry itExercisesSummary
Start here

What you will learn

  • Audit a dataset from question to documented findings.
  • Apply structure, type, quality, and ethics checks.
  • Produce a concise data-readiness report.
  • Prepare the dataset for future Excel, SQL, Power BI, and Python work.
01

Project brief

You are supporting a retail manager who wants to understand sales performance by month, region, channel, and product category. Before analysis, you must determine whether the provided synthetic dataset is structurally and analytically ready.

02

Required audit

Document the row grain, key fields, data types, time coverage, source assumptions, and target questions. Profile row count, duplicate keys, missing required values, invalid categories, impossible quantities, arithmetic consistency, and extreme revenue or profit values.

03

Analytical summary

After quality checks, calculate a small set of descriptive outputs: total revenue, total profit, order count, median order value, monthly trend, top categories, regional contribution, and loss-making observations. Keep business findings separate from data-quality findings.

04

Deliverable

Produce a one-page data-readiness brief with: question, dataset scope, grain, quality scorecard, three evidence-based findings, one limitation, one recommended next analysis, and a change log. Save any cleaned file separately from the original.

Vocabulary

Key terms

Data audit

A documented review of structure, quality, provenance, and fitness for use.

Readiness

The degree to which data can safely support a defined analytical purpose.

Quality scorecard

A concise report of checks, failures, severity, and action.

Change log

A record of transformations and corrections applied to data.

Example

Suggested project workflow

Use the included retail_sales.csv and data dictionary.

  1. 1

    Read the project brief and write three analytical questions.

  2. 2

    Inspect the data dictionary and confirm one-row meaning.

  3. 3

    Profile structure and quality before calculating KPIs.

  4. 4

    Create summary tables and one trend chart.

  5. 5

    Investigate at least one unusual value.

  6. 6

    Write findings with units, time period, and limitations.

  7. 7

    Save a README and change log.

Conclusion

The project is complete when another learner can understand your question, repeat the audit, and trace each conclusion to evidence.

Summary

What to remember

  • Define questions before calculating.
  • Audit structure and quality before business interpretation.
  • Separate quality findings from business findings.
  • Preserve raw data and document changes.
