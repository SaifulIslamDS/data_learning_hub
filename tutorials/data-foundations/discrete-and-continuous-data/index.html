Discrete and Continuous Data

Numerical variables can represent counts or measurements. Learn why the distinction affects possible values, charts, probability models, and data collection.

◷ 35 minBeginner
ObjectivesLearnExampleTry itExercisesSummary
Start here

What you will learn

  • Define discrete and continuous variables.
  • Classify counts and measurements.
  • Understand recorded precision.
  • Recognize when rounding changes interpretation.
01

Discrete data

Discrete numerical data take separate countable values, usually from counting: number of orders, defects, students, or website sessions. Values between valid counts may be impossible; a household cannot contain 3.6 people in one observation.

02

Continuous data

Continuous data arise from measurement and can theoretically take any value within an interval: weight, temperature, time, distance, or revenue measured with finer precision. Recorded values are always rounded to the precision of the instrument or system.

03

Context matters

Age can be continuous when measured precisely but appears discrete when recorded in completed years. Money is technically recorded in currency units, yet often treated as continuous for analytical models. State the operational definition and precision rather than relying only on labels.

Vocabulary

Key terms

Discrete

Countable numerical values with gaps between possible values.

Continuous

Measured numerical values that can vary across an interval.

Precision

The smallest unit or decimal detail recorded.

Rounding

Replacing a value with a nearby value at a chosen precision.

Example

Delivery operations

A courier records packages per rider, delivery duration, distance, and customer rating.

  1. 1

    packages is a discrete count.

  2. 2

    duration and distance are continuous measurements.

  3. 3

    rating 1–5 is ordinal categorical, not continuous.

  4. 4

    If duration is rounded to whole minutes, the recorded values look discrete but the underlying concept remains continuous.

Conclusion

Classification should reflect how the quantity is generated and used.

Summary

What to remember

  • Measurements are usually continuous.
  • Recorded precision does not always change the underlying type.
  • Context and operational definitions matter.
