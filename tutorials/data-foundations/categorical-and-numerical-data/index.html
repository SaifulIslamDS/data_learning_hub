Categorical and Numerical Data

Classify variables by what their values mean. This choice controls valid summaries, charts, models, and interpretations.

◷ 35 minBeginner
ObjectivesLearnExampleTry itExercisesSummary
Start here

What you will learn

  • Distinguish categorical and numerical variables.
  • Recognize identifiers disguised as numbers.
  • Choose suitable summaries for each type.
  • Avoid meaningless arithmetic.
01

Categorical data

Categorical variables place observations into labels or groups: district, product category, payment method, or yes/no status. Useful summaries are counts, proportions, mode, cross-tabulations, and bar charts. Category codes such as 1=Dhaka and 2=Khulna are still labels.

02

Numerical data

Numerical variables represent quantities where arithmetic is meaningful: age, units sold, revenue, weight, or duration. Depending on measurement scale and distribution, analysts use totals, means, medians, spread, histograms, and numerical models.

03

Meaning before storage type

Software may store a value as a number, text, date, or Boolean, but analytical type depends on meaning. Postal code, phone number, and customer ID may contain digits but are categorical identifiers. A star rating is ordinal categorical even though 1–5 are numbers.

Vocabulary

Key terms

Categorical variable

A variable whose values represent labels or groups.

Numerical variable

A variable whose values represent measurable or countable quantities.

Binary variable

A categorical variable with two states.

Paid / unpaid

Identifier

A label used to distinguish records, not a quantity to average.

Example

Classifying an HR dataset

Fields: employee_id, department, age, monthly_salary, performance_rating, resigned.

  1. 1

    employee_id is a categorical identifier.

  2. 2

    department and resigned are categorical.

  3. 3

    age and monthly_salary are numerical.

  4. 4

    performance_rating is usually ordinal categorical unless a validated numerical scale justifies arithmetic.

Conclusion

Correct typing prevents invalid summaries such as the average employee ID or an unjustified mean of category codes.

Summary

What to remember

  • Type variables by meaning, not appearance.
  • Categorical variables use counts and proportions.
  • Numerical variables support meaningful arithmetic.
  • Identifiers are labels even if stored as numbers.
