## Release boundary

The release is a complete static educational foundation rather than a substitute for a university textbook, full statistical software suite, production data platform, or expert review in high-stakes work. Advanced topics are structured introductions with assumptions and limitations. Browser laboratories cover selected high-value methods and can be extended through the documented architecture.

## Deployment action

Before public launch, replace the placeholder origin `https://statistics-learning-hub.netlify.app` when the final Netlify URL is known, regenerate the pages and sitemap, run `npm test`, then deploy the updated commit.
