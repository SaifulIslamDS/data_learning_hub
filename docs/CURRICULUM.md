## Portfolio project curriculum

Each project applies a consistent eight-phase model:

1. Frame
2. Understand
3. Prepare
4. Analyze
5. Implement
6. Communicate
7. Validate
8. Portfolio

The projects deliberately reuse the platform’s core toolchain. Learners are expected to reconcile definitions and totals between tools instead of treating every implementation as a separate answer.
