A reference is invalid, often after deletion.

#SPILL!

An error indicating the result cannot occupy its required cells.

AND

Returns TRUE only when all arguments are TRUE.

AVERAGE

Returns the arithmetic mean of numeric values.

AVERAGEIF

Averages values meeting one condition.

AVERAGEIFS

Averages values meeting multiple conditions.

Absolute reference

A reference with fixed row and column.

Add-in

An optional component that extends Excel features.

Analysis ToolPak

Excel’s statistical analysis add-in.

Analytical workflow

A repeatable sequence from question to evidence and communication.

Annotation

Text or markers explaining important chart events.

Append

Combining tables by stacking rows.

Applied Step

One transformation recorded in sequence.

Approximate match

A lookup that chooses a nearest band rather than an exact key.

Argument

An input supplied to a function.

Assumption

A condition required for a method’s interpretation.

Auditability

The ability to trace an output back to its source and transformation.

AutoFill

A feature that copies formulas or extends patterns.

AutoFilter

The dropdown filtering interface on a range or table.

Axis

A scale that maps values to chart position.

Boolean multiplication

A method for combining AND conditions in array formulas.

CLEAN

Removes many nonprinting characters.

CONCAT

Joins text from arguments or ranges.

COUNT

Counts numeric values.

COUNTA

Counts non-empty values.

COUNTBLANK

Counts blank cells in a range.

COUNTIF

Counts cells meeting one condition.

COUNTIFS

Counts records meeting multiple conditions.

CSV

A plain-text comma-separated values file.

Calculated column

A table column where one formula is automatically filled down.

Calculation chain

The dependency order used to recalculate formulas.

Cell address

A column letter and row number identifying a cell.

Color scale

A gradient mapping values to colors.

Comparison

An expression that returns TRUE or FALSE.

Composite key

An identifier formed from more than one field.

Concatenation

Conditional format

Constant

Control check

Control total

A trusted count or sum used for reconciliation.

Correlation

A standardized measure of linear association.

Covariance

A measure of joint variation in original units.

Criteria range

The cells tested against a criterion.

Criterion

The condition used to include a row.

Current region

A block of data bounded by blank rows and columns.

Custom list

A user-defined order such as High, Medium, Low.

DAX

Dashboard brief

The audience, decisions, metrics, and layout requirements for a dashboard.

The whole-number representation of a date.

IF

Returns one value for TRUE and another for FALSE.

IFERROR

Identifier

Include array

Input message

Insight

KPI

Measure

NETWORKDAYS

Name Box

Null

OR

Operator

Outlier

An observation unusually far from the main pattern.

Output sheet

Paste Special

Options for pasting values, formulas, formats, or other components.

Portfolio artifact

Project brief

Query

SUM

SUMIFS

Sums values meeting multiple criteria.
