Domain-specific validity requirement.

CASE

Conditional expression returning one value.

CAST

Explicitly converts a value to another type.

CHECK

COALESCE

COMMIT

Makes transaction changes permanent.

COUNT(*)

Counts rows, including rows containing NULL columns.

CROSS JOIN

CTE

Cardinality

Cartesian product

Case sensitivity

Collation

Column

Comment

Conformed dimension

Constraint

Contract

Control report
