Quick reference

Course glossary

Accuracy

Closeness of recorded data to reality or a trusted reference.

Analytical question

A question that can be investigated with data and has a defined population, measure, comparison, or time period.

Anonymisation

Processing data so individuals are no longer identifiable with reasonably available means.

Bias

Systematic deviation from the truth or target quantity.

Bin

An interval used to group numerical values.

Binary variable

A categorical variable with two states.

Bivariate

Analysis of the relationship between two variables.

Business key

Fields that uniquely identify an entity or event in context.

CSV

A plain-text format for delimited tabular records.

Categorical variable

A variable whose values represent labels or groups.

Change log

A record of transformations and corrections applied to data.

Cluster sample

Natural groups are sampled, then units within selected groups are studied.

Completeness

Presence of required records and values.

Confounder

A variable related to both an exposure and outcome that distorts their association.

Consistency

Logical agreement within and across data sources.

Continuous

Measured numerical values that can vary across an interval.

Coverage

The people, events, places, and periods represented by a source.

Cumulative frequency

Running total of ordered frequencies.

Data

Recorded values or observations with meaning and context.

Data audit

A documented review of structure, quality, provenance, and fitness for use.

Data dictionary

A reference that defines fields, units, codes, and valid values.

Data minimization

Collecting and retaining only data necessary for a defined purpose.

Dataset

A collection of related data prepared for a purpose.

Denominator

The eligible base used to calculate a rate or proportion.

Descriptive statistics

Methods that summarize the data actually observed.

Discrete

Countable numerical values with gaps between possible values.

EDA

Systematic exploration of data using summaries and visualizations.

Evidence

Observed or calculated information relevant to a claim.

Fairness

Assessment of whether data use creates unjustified unequal benefits, errors, or harms.

Frequency

The count of observations in a category or interval.

Grain

The level represented by one row or metric event.

Identifier

A field used to uniquely distinguish records.

Inferential statistics

Methods that use sample evidence to reason about a population.

Insight

A contextual explanation of a meaningful pattern, not just a number.

Interval

Equal differences are meaningful, but zero is not an absence.

Invalid value

A value that violates a documented rule.

JSON

A text format for objects, arrays, and nested key-value data.

Lineage

Trace of how data moved and changed from source to output.

Measurement error

Difference between a recorded value and the intended quantity.

Metadata

Information describing data, such as source, date, field meaning, or file properties.

Metric

A defined quantitative measure used to monitor or evaluate something.

Missingness

The pattern and reason values are absent.

Nominal

Categories without inherent order.

Numerator

The counted or summed quantity above the division line.

Numerical variable

A variable whose values represent measurable or countable quantities.

Observation

One entity or event represented by a row.

Observational unit

The entity or event represented by one row.

Ordinal

Ordered categories with unknown or unequal spacing.

Outlier

An observation unusually distant from a distribution or model pattern.

Parameter

A numerical characteristic of a population.

Pivot longer

Transform repeated measure columns into variable-value rows.

Pivot wider

Spread category values into separate columns.

Population

The entire defined group about which conclusions are intended.

Precision

The smallest unit or decimal detail recorded.

Primary data

Data collected specifically for the current investigation.

Provenance

The documented origin and processing history of data.

Purpose limitation

Using data only for specified, legitimate, compatible purposes.

Quality scorecard

A concise report of checks, failures, severity, and action.

Random error

Unpredictable variation caused by chance processes.

Ratio

Equal differences and a meaningful zero support ratios.

Readiness

The degree to which data can safely support a defined analytical purpose.

Recommendation

A proposed action linked to evidence, constraints, risks, and expected effect.

Relative frequency

Frequency divided by the relevant total.

Reproducibility

Ability to repeat an analysis using documented inputs and steps.

Rounding

Replacing a value with a nearby value at a chosen precision.

Sample

The observed subset of the population.

Sampling frame

The list or mechanism from which the sample is selected.

Schema

The documented structure: fields, types, rules, and relationships.

Secondary data

Existing data reused for a new purpose.

Sensitivity analysis

Checking whether conclusions change under reasonable alternative choices.

Simple random sample

A probability sample in which eligible units are selected randomly.

Statistic

A numerical summary calculated from a sample.

Statistics

Methods and reasoning for collecting, summarizing, analyzing, and interpreting data.

Stratified sample

Samples are drawn separately within defined subgroups.

Table

A rectangular arrangement of rows and columns.

Tidy data

A consistent structure with variables in columns and observations in rows.

Univariate

Analysis of one variable at a time.

Validity

Conformance to defined formats, ranges, and rules.

Value

The entry at the intersection of an observation and variable.

Variable

A characteristic measured or recorded for observations.

Version control

A system or practice for recording changes over time.
